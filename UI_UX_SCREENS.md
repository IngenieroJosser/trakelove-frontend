# Inventario de pantallas LoveTrack

| Pantalla | Objetivo UX | Datos críticos visibles |
|---|---|---|
| Bienvenida | Explicar confianza y valor antes de pedir permisos | Consentimiento, privacidad, precisión |
| Registro | Crear identidad independiente | Nombre, correo, contraseña, consentimiento |
| Inicio de sesión | Acceso recurrente | Credenciales y recuperación |
| Vinculación | Conectar dos cuentas sin acceso unilateral | Código temporal, QR, aceptación |
| Mapa | Estado operativo principal | Posición, precisión, hora, batería, red, movimiento |
| Historial | Reconstruir últimas 24 horas | Horas, llegadas, salidas, permanencia, distancia |
| Lugares | Administrar pines nominales | Nombre, dirección, coordenadas, confirmación |
| Añadir lugar | Seleccionar ubicación exacta | Pin, coordenadas, precisión, distancia interna |
| Detalle del lugar | Auditar una ubicación guardada | Coordenadas, reglas, última visita |
| Alertas | Controlar eventos de llegada/salida | Lugar, regla y estado de cada alerta |
| Ajustes | Administrar cuenta y dispositivo | Compartición, permisos, batería, red, retención |
| Eliminar historial | Ejecutar borrado irreversible seguro | Alcance, confirmación explícita, resultado |
